# J 组 ETF 轮动策略与回测

周二下午量化交易课程 J 组项目：基于动量与趋势过滤的 ETF 轮动策略设计与回测，包含数据接入、月度调仓、交易成本模拟、基准对比与结果可视化。

本项目使用 60 日动量和 120 日均线设计月度 ETF 轮动策略。回测在信号产生后的下一交易日按调整开盘价模拟成交，并与四只 ETF 等权组合和沪深 300 ETF 买入持有比较。

## 运行方法

按 `data/raw/README.md` 将五份原始快照放到 `data/raw/`，然后在项目目录打开终端。使用 Python 3.11 或更高版本。绘图使用系统的微软雅黑、黑体、苹方、Noto Sans CJK SC 或思源黑体。

```bash
python -m pip install -r requirements.txt
python build_report.py
```

脚本读取 `data/raw/` 的五份历史快照，依次清洗行情、生成信号、执行回测并绘图。运行可离线完成。默认输出在 `report/`，其中包含六张图、两份指标表和逐日净值、持仓及逐笔成交。`report/回测输入/` 保存本次实际使用的行情、交易日历与信号。可用 `--output-dir` 指定输出目录，或用 `--raw-dir` 指定相同格式的快照目录。

### 分步运行

```bash
python prepare_data.py
python signals.py
python main.py
```

前两步分别写入 `data/processed/` 和 `data/signals/`，单次回测结果写入 `results/`。回测入口支持 `--split dev|valid|test` 和 `--cost zero_cost|base_cost|double_cost`。运行回测测试可先安装 `pytest`，再执行 `python -m pytest`。

## 数据来源

- 四只 ETF 为 `159915.SZ`、`510300.SH`、`510500.SH` 和 `518880.SH`。Tushare 日线快照覆盖 2015-01-05 到 2025-11-19，使用 `fund_daily`、`fund_adj` 和 `trade_cal`。
- 2025-11-20 至 12-31 的 30 个交易日由新浪财经补齐，每只 ETF 30 条，共 120 条。补充阶段的交易日按补充行情生成，并与两所 2025 年休市公告核对。复权因子采用 Tushare 快照的最后可得值接续。
- 后复权价格等于原始价格乘以当日因子，再除以该 ETF 的首日因子。510300 在 2015-01-20 的除息因子按每份 0.035 元的公告分红额补算。交易日历保留市场开市日，行情保留个别 ETF 的停牌缺口。

## 回测设置

- 2015 年用于指标预热。全样本为 2016—2025 年，开发期为 2016—2021 年，验证期为 2022—2023 年，测试期为 2024—2025 年。各次运行从 10 万元与净值 1 开始。
- 基础成本采用单边手续费 0.03%、单边滑点 0.02%。无风险利率按 0，年化使用每年 252 个交易日。
- E0 等权组合和买入持有在样本首日建仓。E1、E2、E3 可在样本首日执行上一月末信号。图 6 按期末市值计入未平仓持仓，持仓贡献明细同时记录已实现和未实现损益。

## 源码入口

| 文件 | 用途 |
|---|---|
| `prepare_data.py` | 从原始行情、因子和交易日历快照生成并校验回测输入 |
| `signals.py` | 计算动量、均线和月末目标 |
| `backtest.py` | 模拟交易并核算资金、持仓及净值 |
| `main.py` | 按配置和实验情景运行回测 |
| `build_report.py` | 串联各模块，生成回测明细、统计表和图表 |
